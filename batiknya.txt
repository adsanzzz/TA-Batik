Hal ini biasanya terjadi karena model AI Anda mengalami "Softmax Overconfidence" atau kejenuhan pada lapisan aktivasi akhir. Berikut adalah beberapa alasan teknis mengapa tingkat kepercayaan (confidence level) terlihat sama (biasanya 100% atau angka yang sangat mendekati) pada setiap submit:

1. Karakteristik Fungsi Softmax
Pada file train.py baris 88, Anda menggunakan aktivasi softmax:

python
layers.Dense(train_generator.num_classes, activation="softmax")
Fungsi Softmax cenderung "mendorong" satu nilai menjadi sangat dominan (mendekati 1.0) dan nilai lainnya menjadi sangat kecil (mendekati 0.0) jika model sudah sangat yakin atau jika model mengalami overfitting.

2. Pembulatan di Frontend
Di file Scan.jsx baris 130, Anda menggunakan .toFixed(1):

javascript
Tingkat Keyakinan: {(result.confidence * 100).toFixed(1)}%
Jika model memberikan nilai 0.9999 atau 0.9992, keduanya akan dibulatkan menjadi 100.0%. Inilah yang membuat seolah-olah nilainya selalu sama.

3. Overfitting pada Dataset Kecil
Dengan dataset sekitar 1.650 gambar untuk 11 kelas (~150 gambar per kelas), model MobileNetV3 bisa dengan cepat menghafal pola. Jika model terlalu "pintar" menghafal, ia akan memberikan nilai probabilitas yang sangat ekstrem untuk setiap gambar yang mirip dengan data latih.

4. Normalisasi Gambar yang Konsisten
Di predict.py, Anda melakukan pembagian dengan 255.0:

python
img_array = np.array(img) / 255.0
Ini sudah benar dan sama dengan saat training. Namun, jika gambar yang diupload memiliki kontras yang sangat jelas, model akan dengan mudah masuk ke kategori tertentu dengan keyakinan penuh.
